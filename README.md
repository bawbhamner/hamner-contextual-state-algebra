# Hamner Contextual State Algebra (HCSA)
📄 **Full Paper (PDF):**
[Hamner Contextual State Algebra – Robert Hamner](Hamner_Contextual_State_Algebra_Robert_Hamner.pdf)

Author: Robert Hamner

This repository contains a preprint draft of **Hamner Contextual State Algebra (HCSA)**,
an algebraic framework for modeling context-sensitive computation.

The work introduces a context-indexed transition operator that generalizes
classical state-transition systems such as finite-state machines and labeled
transition systems.
